# Dashboard Filter Reference: Tableau → PBI

This document records how Tableau dashboard filter constructs map to PBI **visual-page elements** (slicer widgets on the canvas). It does NOT cover the PBI filter pane ("Filters on this visual / page / report") — those are handled separately via `filterConfig`.

Source of truth for PBI property structures: PBI Desktop-generated PBIR files (reverse-engineered). Microsoft does not publish formal schemas for the `objects.*` properties inside `visualContainer`.

---

## 1. Slicer Widget (Tableau Filter Zone → PBI Slicer)

### Tableau source

A `<zone type-v2='filter'>` element inside `<dashboards><dashboard><zones>`:

```xml
<zone h='18250' id='8'
      name='Sales  Profit'
      param='[federated.xyz].[none:region:nk]'
      type-v2='filter'
      mode='checkdropdown'
      w='18300' x='80900' y='1000' />
```

Key attributes:

| Attribute | Meaning |
|-----------|---------|
| `param` | Identifies the datasource and field: `[datasource_id].[prefix:field_name:suffix]` |
| `mode` | Controls selection behavior and display style (see mode table below) |
| `name` | Source worksheet the filter is scoped to (may be empty = all sheets) |
| `x`, `y`, `w`, `h` | Position in Tableau coordinate units (0–100000) |

**Note on `mode` absence:** When `mode` is absent from `<zones>` (primary layout), it is Tableau's implicit default — equivalent to `checkdropdown` (multi-select list). Device layout zones (under `<devicelayouts>`) may have `mode` set differently for mobile adaptation; those are NOT used for migration.

### PBI output: `visual.json` structure

Generated by `_build_slicer_visual()` in `dashboard.py`. Written to `pages/<SectionId>/visuals/<visual_id>/visual.json`.

```json
{
  "$schema": "https://developer.microsoft.com/json-schemas/fabric/item/report/definition/visualContainer/1.0.0/schema.json",
  "name": "dash_visual_3",
  "position": { "x": 1036, "y": 7, "z": 0, "width": 234, "height": 131 },
  "visual": {
    "visualType": "slicer",
    "query": {
      "queryState": {
        "Values": {
          "projections": [{
            "field": {
              "Column": {
                "Expression": { "SourceRef": { "Entity": "people" } },
                "Property": "region"
              }
            },
            "queryRef": "people.region",
            "active": true
          }]
        }
      }
    },
    "objects": {
      "data": [{
        "properties": {
          "mode": { "expr": { "Literal": { "Value": "'Basic'" } } }
        }
      }],
      "selection": [{
        "properties": {
          "singleSelect":             { "expr": { "Literal": { "Value": "false" } } },
          "strictSingleSelect":       { "expr": { "Literal": { "Value": "false" } } },
          "selectAllCheckboxEnabled": { "expr": { "Literal": { "Value": "true"  } } }
        }
      }]
    },
    "drillFilterOtherVisuals": true
  }
}
```

### Property reference

#### `objects.data[0].properties`

Controls slicer display style.

| PBI property | Type | Notes |
|---|---|---|
| `mode` | string literal | Display style of the slicer widget. See mode table below. |

#### `objects.selection[0].properties`

Controls selection behavior. Written **only** when `multi_select=True` and `slicer_mode != "Between"`.

| PBI property | Value | Meaning | Equivalent Tableau behavior |
|---|---|---|---|
| `singleSelect` | `"false"` | Allows multi-item selection | Filter accepts multiple selected values |
| `strictSingleSelect` | `"false"` | Click alone selects/deselects; **no CTRL required** | Tableau list filters always click-to-toggle |
| `selectAllCheckboxEnabled` | `"true"` | Shows "Select All" checkbox at top | Tableau filter list has "(All)" option |

**Important:** `singleSelect` belongs in `objects.selection`, NOT `objects.data`. PBI silently ignores unknown properties in `objects.data`, so placing it there has no effect.

#### Top-level `visual` properties

| PBI property | Value | Meaning |
|---|---|---|
| `drillFilterOtherVisuals` | `true` | Slicer selection cross-filters all chart visuals on the same page (equivalent to Tableau dashboard filter applying to all worksheets) |

### Mode mapping: Tableau `mode` → PBI `objects.data.mode` + `multi_select`

| Tableau `mode` attribute | PBI `mode` value | `multi_select` | Selection behavior |
|---|---|---|---|
| *(absent / empty)* | `Basic` | `True` | Multi-select list (Tableau implicit default) |
| `checkdropdown` | `Basic` | `True` | Multi-select list |
| `radiolist` | `Basic` | `False` | Single-select radio buttons |
| `dropdown` | `Dropdown` | `False` | Single-select dropdown |
| `compact` | `Dropdown` | `False` | Single-select compact dropdown |
| `type_in` | `Dropdown` | `False` | Single-select type-in dropdown |
| `slider` | `Between` | N/A (range) | Range slider — no `objects.selection` written |

**Single-select modes** (`radiolist`, `dropdown`, `compact`, `type_in`): `objects.selection` is omitted entirely, leaving PBI's default single-select behavior.

**Range mode** (`slider` → `Between`): `objects.selection` is omitted regardless of `multi_select`.

---

### Coordinate scaling

Tableau zone coordinates use a 0–100000 unit space. PBI canvas is 1280×720 px.

```
pbi_x = round((tab_x / 100000) * 1280)
pbi_y = round((tab_y / 100000) * 720)
pbi_w = round((tab_w / 100000) * 1280)
pbi_h = round((tab_h / 100000) * 720)
```
